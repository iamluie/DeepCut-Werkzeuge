# DeepCut-Werkzeuge

Unveränderte Kopien der Werkzeuge, die DeepCut bei der ersten Einrichtung lädt –
als Ersatzquelle, falls die Originalquelle nicht erreichbar ist.

| Datei | Original |
|---|---|
| ffmpeg-arm64.zip, ffprobe-arm64.zip | https://ffmpeg.martin-riedl.de (macOS arm64, FFmpeg 9.0.2) |
| ffmpeg-x86_64.zip, ffprobe-x86_64.zip | https://ffmpeg.martin-riedl.de (macOS amd64, FFmpeg 9.0.2) |

DeepCut prüft jede Datei per SHA-256, bevor es sie benutzt.

FFmpeg steht unter LGPL/GPL. Quellcode: https://ffmpeg.org/download.html ·
Build-Skripte des Originals: https://git.martin-riedl.de/ffmpeg/build-script
